# 微信表情包大师（Eagle 插件）

将 Eagle 素材库中的图片快速制作成 **300 × 300 px、1:1 比例**的表情包。支持批量逐张处理、裁剪、旋转、翻转、文字叠加，以及保存回 Eagle。

## 功能

- 固定 1:1 裁剪比例，导出统一为 300 × 300 px。
- 顺时针/逆时针旋转 90°、水平翻转。
- 文字编辑：支持换行，拖动定位，设置字号、颜色和黑色描边。
- 实时预览：预览与导出共用同一套 Canvas 绘制逻辑。
- 批量处理：按 Eagle 当前选中项目建立队列，可跳转并显示完成状态。
- PNG 或 JPG 导出（JPG 质量 0.9）。
- 可添加 Eagle 标签、指定目标文件夹。
- 记住文字、位置、样式、格式、标签及文件夹等偏好设置。
- 可选删除原图，默认关闭；只有新文件成功导入后才尝试将原图移入回收站。

## 安装

1. 下载并解压本仓库。
2. 打开 Eagle，进入 **插件 → 开发者选项 → 从文件夹导入插件**。
3. 选择包含 manifest.json 的项目目录。
4. 在 Eagle 中选中图片，启动“微信表情包大师”。

## 使用

1. 选中一张或多张图片并启动插件。
2. 在中央画布调整裁剪区域，使用工具栏旋转或翻转。
3. 在右侧输入文字并拖动预览文字调整位置。
4. 设置格式、标签和目标文件夹。
5. 点击“保存并下一个”。保存失败时会保留当前项目，修复问题后可重试。
6. 全部处理完成后，插件提示结果并尝试聚焦 Eagle。

## 安全说明

- 删除原图默认关闭。启用后，插件会先等待 eagle.item.addFromPath() 成功完成，再调用 eagle.item.moveToTrash()。
- 导出使用系统临时目录；无论导入成功或失败，都会尝试清理临时文件。
- 如导入或回收站操作失败，请检查 Eagle 权限、目标文件夹 ID 和磁盘空间。
- Cropper.js 1.5.13 当前通过 cdnjs CDN 加载，首次运行需要网络访问；离线使用需要将依赖随插件打包。
