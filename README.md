# 微信表情包大师 (WeChat Sticker Pro) - Eagle 插件

一款为 Eagle 设计的表情包制作插件，支持裁剪、旋转、文字叠加，一键生成符合微信规范的 300x300 表情包。

## 功能特性

- **智能裁剪**：强制 1:1 比例，自动缩放至 300x300px
- **旋转/翻转**：支持左旋、右旋、水平翻转
- **可拖拽文字**：在图片上自由拖拽定位文字，实时预览最终效果
- **文字样式**：自定义字号（12-72px）、颜色、黑色描边开关
- **实时预览**：右侧面板实时显示输出效果（含文字）
- **批量处理**：支持一次选中多张图片进入序列处理流程
- **格式选择**：支持导出为 JPG 或 PNG 格式
- **库深度集成**：自动添加标签、移动至指定文件夹，并可选在保存后删除原图
- **设置记忆**：自动记录文字、导出等配置，下次打开自动恢复
- **保存后聚焦**：处理完成后自动聚焦 Eagle 主窗口并打开目标文件夹

## 安装说明

1. 打开 Eagle
2. 进入菜单：**插件** → **开发者选项** → **从文件夹导入插件...**
3. 选择此文件夹 (`wechat-sticker-pro`)

## 使用方法

1. 在 Eagle 库中选中一张或多张图片
2. 右键点击并选择"微信表情包大师"，或通过插件栏打开
3. 在图片上拖拽文字框调整位置，在右侧面板调整文字样式
4. 使用底部工具栏旋转/翻转图片
5. 点击"保存并下一个"开始批量处理序列
