# 微信表情包大师 (WeChat Sticker Pro) - Eagle 插件

一款为 Eagle 设计的强大插件，用于快速生成微信表情包。

## 功能特性
- **智能裁剪**：强制 1:1 比例，完美适配微信表情包规范。
- **自动缩放**：自动调整至 300x300px。
- **批量处理**：支持一次选中多张图片进入序列处理流程。
- **格式选择**：支持导出为 JPG 或 PNG 格式。
- **库深度集成**：自动添加标签、移动至指定文件夹，并可选在保存后删除原图。
- **设置记忆**：自动记录您常用的标签和导出配置。

## 安装说明
1. 打开 Eagle。
2. 进入菜单：**插件** -> **开发者选项** -> **从文件夹导入插件...**。
3. 选择此文件夹 (`wechat-sticker-pro`)。

## 使用方法
1. 在 Eagle 库中选中一张或多张图片。
2. 右键点击并选择“微信表情包大师”，或通过插件栏打开。
3. 在界面中调整裁剪框，并在右侧侧边栏设置偏好。
4. 点击“保存并下一个”开始批量处理序列。
