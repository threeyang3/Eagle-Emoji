# 微信表情包大师（Eagle 插件）

将 Eagle 素材库中的图片制作成 **300 × 300 px、1:1 比例**的微信表情包。支持批量处理、多文字图层、样式模板、图片裁剪与文件大小控制。

## 功能

### 图片与批量处理
- 固定 1:1 裁剪比例，导出统一为 300 × 300 px。
- 旋转 90°、水平翻转。
- 批量队列支持跳转、跳过和完成状态。
- 每张图片独立记住本次会话中的裁剪、旋转和翻转状态。

### 多图层文字编辑
- 一张表情包可添加多个独立文字图层，分别设置内容、位置、字号、颜色、字体、描边和底色。
- 点击图层列表切换当前编辑对象；直接拖动画布上的文字图层调整位置。
- 支持多行文字、长文本自动换行及常见 Emoji。
- 可保存常用文字样式为模板，之后应用到其他文字图层，也可以删除不再需要的模板。
- 样式模板保存在 Eagle 插件本地设置中，不会上传。

### 导出
- PNG 或 JPG；JPG 质量可调（40%–100%）。
- 可设置最大导出文件大小（50–2048 KB）。
- JPG 超过大小上限时自动逐级降低压缩质量；如果达到最低质量仍超限，提示用户调整设置，不会静默突破上限。
- PNG 无损格式无法通过质量参数压缩，若超过上限需改用 JPG 或提高文件大小上限。
- JPG 导出透明图片时使用白色底色，避免透明区域变黑。

### Eagle 素材管理
- 可添加标签、指定目标文件夹。
- 可选删除原图，默认关闭；新文件成功导入后才尝试将原图移入回收站。
- 如果导入成功但原图回收站操作失败，不会重复导入表情包。

## 安装

1. 下载并解压本仓库。
2. 打开 Eagle，进入 **插件 → 开发者选项 → 从文件夹导入插件**。
3. 选择包含 `manifest.json` 的项目目录。
4. 在 Eagle 中选中图片，启动“微信表情包大师”。

## 使用

1. 选中一张或多张图片并启动插件。
2. 在中央画布调整裁剪区域，使用工具栏旋转或翻转。
3. 点击“添加文字”创建图层；选择图层后编辑文字与样式，并拖动画布上的文字定位。
4. 如需复用样式，保存为模板，再选择模板并点击“应用”。
5. 设置导出格式、JPG 质量、最大文件大小、标签和目标文件夹。
6. 点击“保存并下一个”。保存失败时会保留当前项目，修复问题后可重试。

## 开发检查

安装 Node.js 后，在项目根目录执行：

```bash
npm run check
```

该命令检查 manifest JSON、JavaScript 语法、脚本引用的 DOM ID、本地 Cropper.js 文件、多图层/模板/大小限制关键代码及原图保护顺序。它不能替代 Eagle 内的真实交互测试。

## 依赖与离线运行

Cropper.js 1.5.13 的 JS/CSS 已随项目放在 `vendor/cropperjs/`，包含 MIT License；裁剪功能不依赖运行时 CDN，可离线使用。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | Eagle 插件元数据及窗口配置 |
| `index.html` | 插件界面 |
| `script.js` | 图片处理、图层、模板、队列和导入 |
| `style.css` | 界面样式 |
| `scripts/check.js` | 静态完整性检查 |
| `vendor/cropperjs/` | 本地裁剪依赖及许可证 |

当前开发版本：**1.3.0**。发布前仍需在 Eagle 桌面环境完成真实图片编辑、导入和回收站回归。
