# 微信表情包大师（Eagle 插件）

将 Eagle 素材库中的图片快速制作成 **300 × 300 px、1:1 比例**的表情包。支持批量逐张处理、裁剪、旋转、翻转、文字排版，以及保存回 Eagle。

## 功能

### 图片处理
- 固定 1:1 裁剪比例，导出统一为 300 × 300 px。
- 顺时针/逆时针旋转 90°、水平翻转。
- 批量队列：从 Eagle 当前选中项目建立队列，可跳转、跳过并显示完成状态。
- **记住每张图片的裁剪状态**：在队列中切换图片再返回时，恢复该图片的裁剪框、旋转和翻转状态。

### 文字编辑
- 支持多行文字及常见 Emoji。
- 拖动定位，设置字号、颜色、字体。
- 可启用黑色描边并调整描边宽度。
- 可启用文字底色并自定义底色。
- 长文本会按导出画布宽度自动换行；预览和导出使用一致的换行规则。

### 导出与 Eagle 管理
- PNG 或 JPG 导出；JPG 质量可调（40%–100%）。
- 可添加 Eagle 标签、指定目标文件夹。
- 记住文字、位置、样式、格式、质量、标签及文件夹等偏好设置。
- 可选删除原图，默认关闭。导入新表情包成功后才尝试将原图移入回收站；如果回收站操作失败，不会重复导入表情包。

## 安装

1. 下载并解压本仓库。
2. 打开 Eagle，进入 **插件 → 开发者选项 → 从文件夹导入插件**。
3. 选择包含 `manifest.json` 的项目目录。
4. 在 Eagle 中选中图片，启动“微信表情包大师”。

## 使用

1. 选中一张或多张图片并启动插件。
2. 在中央画布调整裁剪区域，使用工具栏旋转或翻转。
3. 在右侧输入文字、调整字体和样式，并拖动预览文字调整位置。
4. 设置格式、JPG 质量、标签和目标文件夹。
5. 点击“保存并下一个”。保存失败时会保留当前项目，修复问题后可重试。
6. 切换到其他图片再返回时，会恢复本次会话中该图片的裁剪状态。
7. 全部处理完成后，插件提示结果并尝试聚焦 Eagle。

## 安全说明

- 删除原图默认关闭。启用后，插件先等待 `eagle.item.addFromPath()` 成功完成，再调用 `eagle.item.moveToTrash()`。
- 如果表情包导入成功但原图移入回收站失败，插件会提示这一部分失败，并继续队列，不会重新导入同一张表情包。
- 导出使用系统临时目录；无论导入成功或失败，都会尝试清理临时文件。
- 如导入或回收站操作失败，请检查 Eagle 权限、目标文件夹 ID 和磁盘空间。
- Cropper.js 1.5.13 已随插件放在 `vendor/cropperjs/`，包含 MIT License；图片裁剪功能不再依赖外部 CDN，可离线运行。

## 开发检查

项目提供无第三方依赖的静态检查脚本。安装 Node.js 后，在项目根目录执行：

```bash
npm run check
```

该命令检查 manifest JSON、JavaScript 语法、脚本引用的 DOM ID、本地 Cropper.js 文件及关键数据安全约束。它不能替代 Eagle 内的真实交互测试。
